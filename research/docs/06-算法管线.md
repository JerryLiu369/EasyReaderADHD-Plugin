# 06 · 算法管线 v14：文本 → 加粗文本

> 实现唯一来源：`eval/mvp.py`。本文档是它的中文复述，改代码必须同步改这里。
> 状况：prompt 冻结 en-v3，算法冻结 v14（2026-10-13；停用词全公有化，零手写）。

## 总览

```
段落文本 → [A 候选器] → [B Jev 法官] → [C 渲染器] → <strong> 加粗 HTML
            本地·免费      联网·按量      本地·免费
            高召回         批量打分排序    Top-K+锚点
```

一句话：候选器只管"别漏"（宁可多给），Jev 只管"排序"（不直接决定加粗），
渲染器只管"取多少、在哪落点"（覆盖率 12% + 长子句锚点）。

## A · 候选器（`build_candidates`）

输入：一段文本 + Node `Intl.Segmenter('zh', word)` 切出的 `[{text, off}]`（复用系统 ICU，零依赖）。

1. **内容过滤**（`is_content`）：去空、纯标点、单字虚词。单字虚词表 `FUNC_CHARS`
   （的了着过…按，v10 补介词"按"）——E1 已证它们得分垫底，直接省 ~30% 问题数。
2. **四路候选**：
   - `raw`：单个分词单元。
   - `pairs`：相邻两单元直拼（中间必须无字符，或仅空格/间隔号·・‧•/．，不跨标点）。
     任一半命中 `HALF_BAD = STOP ∪ FUNC_CHARS` 则整条丢；另禁 `有+纯数字`
     （有|183 是存在句胶水，信息全在数量短语里；有线/有效类第二半是 CJK，不受影响）。
   - `runs`：连续单字 CJK 整体成块（2–6 个汉字），治音译名被切碎
     （查尔斯·蒂利 / Charles Tilly 一次成块，碎词自动丢——宁粗勿碎；
     v11 起允许一个 ASCII 首字母开头：W.布莱恩·阿瑟类；
     v12 起允许混入最多 1 个 2 字 CJK 词：地缘+竞争/空间+维度/保护+伞/整+条+航道。
     防线：位来自全球（1单+2多）、全国锦标（0单）永不可建；首尾单元禁 STOP 多字词
     （防我们屈髋抬腿类借 licensed 通道还魂）。
   - `qty`（v10）：数量短语 `NUM + 可选量词 + 1–2 名词`。
     NUM = 阿拉伯/全角数字 + 汉字数词（一二三…亿两几多半）；量词表 `CLF`（约 70 字常用量词）。
     建 183个国家 / 四款字体 / 30分钟 / 两度会晤 / 十年前 / 十几张不同风格。
     关键：扫**未过滤**的分词序列（量词本身就是虚词，过滤后扫对不上）；
     1 名词和 2 名词双变体都建，子串关系由渲染侧裁决。CJK 总量 ≤8。
   - 三字候选**已删除**（v9，消融 +0.035：三字是 E1 粘连碎片的主产地）。
3. ** span 卫生**：两端修剪引号括号（`clean_span`，offset 还回原文）；
   长度 <2 丢；首单元是单字虚词则整条丢、`的/是`开头一律丢
   （地方/地球类豁免：看的是首**单元**不是首字）；
   单 token 虚词头 + ASCII/数字剥头（有183→183，地方/有用类纯 CJK 不动）；
   纯数字丢（含单位的 60Kstar 不受影响）；`STOP` exact 丢。
- 停用词（v14 起零手写）：四公开表（哈工大/百度/中文/川大）**四表共识**合并 338 条
  （多字 315 + 单字 23），生成器 `eval/stopwords/merge_stopwords.py`，可复现。
  按长度分层用：全表 exact；多字 + 23 单字共识用于双字半边、runs 首尾、数量短语名词单元。
  单字条目永不当自由半边（否则中国/本质/十年前 全杀——HIT 全表单测时的实证坑）。
- 单字虚词 `FUNC_CHARS`：v12 移出“地”（内容语素地缘/地球/地址兼助词）。
  v13 删单字“利”。v14 起该表与 STOP_SINGLE_CONSENSUS 并存，均为功能字白名单性质，
  由四表共识 + 门下验证约束，人工只允许删（删需同级门测）。
4. **宁粗勿碎**：任一候选若被另一个更长的候选完全覆盖则出局
   （蒂利 ⊂ 查尔斯·蒂利，只留后者；重叠但互不包含的不动，交给贪心）。

## B · 法官（`score_terms` + `call_jev`）

- 同段同词只问一次（问题数 -30%，永久省 token）。
- 每批 50 题（tune D 验证：与 25/批同延迟，请求数减半），state = 整段原文。
- 每题一个 `noul` 问题，wording en-v3（英文指令，state 保持中文）：
  - Q: "If a reader had to retell this paragraph's specific points — who, which theory or
    scheme, what mechanism or evidence — would missing `target` make the retelling vaguer?"
  - true: "A name, theory/scheme label, mechanism, number, or example that carries the
    argument; removing it loses attribution or specifics"
  - false: "A general topic word, filler, scene-setting, or connective; removing it changes
    nothing specific. Also a phrase that begins with a verb or trails off with a particle,
    conjunction, or demonstrative"
  - 零语料例子（防过拟合铁律：prompt 里不许出现任何调参语料的词）。
- 返回的 `noul` 即该词得分，只用于**排序**，不设绝对阈值
  （E1 发现 26% 好词 < 0.5，阈值会误杀四分之一）。
- 工程：`(WORDING_VER|state|term)` sha1 缓存，调渲染零成本；
  429/529 指数退避，其余网络抖动短退避，6 次重试；`eval/.usage.json` 记账。

## C · 渲染器（`render_para`）

输入：文本 + 每个候选 occurrence 的 `(起, 止, 词, 分)`。

1. **贪心取**：unique 词按分排序，依次取不重叠 span，直到**本句**覆盖率达标。
   预算按顶层句分配（每句 12% 字符覆盖率，<8 字句子跳过；v12 以前是全局抢预算，
   必然前密后疏）。同词只取首次出现（全段去重）；已选词的子串/超串一律抑制。
   预算与锚点同受 `SCORE_FLOOR = 0.25`：judge 打进地下室的不买，句子空着
   （没做到 0.19/不甚明 0.20 类，标错比不标更坏）。
2. **长子句锚点**：按 `。！？…\n；：，、` 切子句，内容 ≥15 字的长子句若无命中，
   补该子句内最高分候选（不复用已选词及子串，宁缺勿滥优先于每句有锚）。
   短子句不强制（防密度膨胀）。动机：目光跟踪负担来自长连续字符。
3. **外观合并**：原文相邻（gap 为空）的已选 span 合并显示，总长 ≤6 字
   （防"酸痛的是大腿前侧"类 10 字怪串）。
4. 输出：原文转义 + `<strong>` 包裹，加粗只加字重 + 0.08em 左右 padding，无色块。

## 已知弱项（不修，等证据）

- ICU 切碎三字以上合成词的重缝碎片（伞美国/美元首赢过保护伞/中美元首）：分词器质量问题，
  代码侧无干净解（v9 接受过 积着十几个，同类）。
- Judge 给动词头/长 span 打高分是模型偏好，wording 已尽力，改 wording = 全量缓存失效，
  非必要不动。
- 抒情与文言 moral-core（江東父兄类）系统性低估：跨年代一致，非退化，不堆规则。
